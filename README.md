# AI Spam Detector

A small Flask web app that uses a TF-IDF + Logistic Regression model to classify messages as spam or not spam.

## Project structure

```
AI Spam Detector/
├── app.py
├── train_model.py
├── spam.csv
├── requirements.txt
├── templates/
│   └── index.html
└── static/
    ├── style.css
    └── script.js
```
